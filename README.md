# Genius Foods — Landing Page

Landing page pública da Genius Foods, cardápio digital para restaurantes pelo WhatsApp.

## Stack

- [Next.js 14](https://nextjs.org/) (App Router)
- TypeScript
- Tailwind CSS

Página estática (SSG), sem autenticação e sem banco de dados.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Build de produção

```bash
npm run build
npm run start
```
